## ПР2. Ответы на контрольные вопросы

1. У double есть небольшая погрешность при вычислениях: 0.1 + 0.2 в итоге дают 0.30000000000000004, а не 0.3. С деньгами так работать нельзя, поэтому берут decimal, он считает без таких ошибок

2. Когда число выходит за максимум, оно идёт по кругу и начинается заново с минимального значения. К примеру, у byte после 255 следующим будет 0

3. В Python одна и та же переменная может хранить данные разных типов. В C# при использовании var тип выбирает компилятор в момент сборки, и после этого поменять его уже нельзя

4. Это всегда строка (string), что бы ни ввёл пользователь, даже если там одни цифры

5. Если в int.Parse передать буквы, то возникнет исключение и программа аварийно завершится. int.TryParse так не делает, он молча возвращает false

6. false сообщает, что превратить строку в число не удалось. В таком случае в out-переменную попадает 0

7. Пользователь легко может ошибиться и вместо возраста набрать буквы. TryParse в такой ситуации не даёт программе упасть
